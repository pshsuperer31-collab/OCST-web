# OCST · 변화도 (變化圖)

**Oriental Change Scan Tool** — 주역을 점술이 아니라 **변화 진단 도구**로 쓰는 앱.

OMST(사람·기질)와 짝을 이룹니다. OMST가 사람의 항상성을 읽는다면, OCST는 상황의 시간성을 읽습니다.

## 점과 갈라지는 지점

점은 괘를 무작위(蓍草·동전)로 얻습니다. 그래서 재현이 안 되고, 그게 점의 본질입니다.

OCST는 괘를 **상황의 구조에서 유도**합니다. 같은 입력이면 같은 괘가 나오고, 상황이 움직인 뒤 다시 스캔하면 괘가 이동합니다. 재현·추적이 되는 것 — 그게 이 도구의 근거입니다.

## 괘를 얻는 방법

예/아니오 6문항이 곧 여섯 효입니다. 답하는 순간 64괘가 유일하게 결정됩니다.

**하괘 — 내가 딛고 선 쪽**

| 효 | 이름 | 묻는 것 |
|---|---|---|
| 初 | 마음의 불 | 이 일이 자꾸 떠올라 안 하면 답답한가 |
| 二 | 손에 쥔 것 | 지금 가진 것으로 시작할 수 있는가 |
| 三 | 드러난 움직임 | 남이 봤을 때 이미 시작한 것으로 보이는가 |

**상괘 — 내가 통제 못 하는 쪽**

| 효 | 이름 | 묻는 것 |
|---|---|---|
| 四 | 판의 바람 | 요즘 분위기·여건이 괜찮은 편인가 |
| 五 | 열쇠 쥔 곳 | 승인·수요·허락을 쥔 쪽이 움직이는가 |
| 上 | 끝의 문 | 끝 그림이 그려지는가 |

여기에 **국면(진행 단계)** 한 문항이 붙어 主爻를 정합니다. 점의 변효를 대체하는 축입니다.

## 리포트 6면

| 면 | 근거 | 얻는 것 |
|---|---|---|
| ① 지금 판 | 본괘 | 상·하 구조로 읽는 한 줄 진단 |
| ② 국면 | 主爻 효사 | 吉凶悔吝无咎 판정 |
| ③ 속사정 | 互卦 | 겉과 다른 실제 동력 |
| ④ 상대의 판 | 綜卦(도전) | 저쪽에서 본 같은 상황 |
| ⑤ 이렇게 하면 | 之卦 | 한 획을 바꿨을 때 도달점 |
| ⑥ 다음 국면 | 序卦傳 | 이 상황의 다음 마디 |

## 판정의 근거

`judge()`는 계수를 추정하지 않습니다. 384효 전수 집계를 그대로 씁니다.

효위치(6) × 자기음양(2) × 짝효음양(2) = **24셀, 각 정확히 16효**. 中은 효위치로, 正은 효위치+자기음양으로 결정되므로 자유변수가 24개뿐입니다. 표본이 아니라 전수라 끼워맞추기가 아닙니다.

우선순위는 **효사에 명시된 점사어 > 통계**입니다. 점사어가 없는 효만 위 분포로 읽고, 화면에 어느 쪽인지 밝힙니다.

吉과 凶이 한 효에 함께 있는 자리(屯 五 `小貞吉 大貞凶` 등)는 **「갈림」** 으로 표시합니다. 조건이 결과를 가르는 자리입니다.

## 구조

```
index.html          앱 전체 (단일 파일 · 외부 의존 0 · 더블클릭으로 열림)
hex64.json          64괘 binary·번호·이름
yao-b1.json         효사 1~16괘
yao-b2.json         효사 17~32괘
yao.json            위 둘을 병합한 것
empiric.js          판정 실측 테이블
calibrate.mjs       384효 집계 → EMPIRIC 생성
revise-copy.mjs     문항 카피 개정 스크립트
```

`index.html`에는 세 개의 주입 토큰이 있습니다. 데이터를 갱신할 때는 토큰 자리에 넣습니다.

```
/*__HEX64__*/    ← hex64.json
/*__EMPIRIC__*/  ← empiric.js (calibrate.mjs가 생성)
/*__YAO__*/      ← yao.json
```

주입 예:

```bash
node -e "const fs=require('fs');let h=fs.readFileSync('index.html','utf8');h=h.replace('/*__YAO__*/{}',fs.readFileSync('yao.json','utf8'));fs.writeFileSync('index.html',h)"
```

## 표기 규칙

- binary는 **상괘3 + 하괘3**, 각 소성괘는 **위→아래** 순. 초효가 마지막 자리입니다.
  - 지천태 `000111` / 천지비 `111000` / 수뢰둔 `010001`
- 8괘 한글 표기에서 離는 **리**(이 아님). 순서는 건태리진손감간곤.

## 현재 상태

- 엔진 · 리포트 6면 · 판정 테이블: 완료 (64괘 × 6효 전수 검증)
- 효사: **32/64괘 (192효)** 이관 완료. 33~64괘는 미이관 (해당 괘는 통계로 폴백)
- 64괘 상황용 서술: 미착수

효사 원문·직역·판정·구조 분석(正/中/應/承乘)은 노션 **「효별 궁리 분석(爻辭 構造)」** DB에서 가져왔습니다. 384효 64괘 전수.
